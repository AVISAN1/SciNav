# SciNav

Учебный проект по цифровым медиа. Адаптивная страница поиска научных публикаций по макету Figma.

## Макет

[Figma — страница 03_Finaly](https://www.figma.com/design/uDwovncQ7C44KhJiqFlG1q/Untitled?node-id=154-2)

Перед сдачей проверьте доступ к макету для просмотра. Доступ меняется в Figma через Share.

## Запуск через Live Server

1. Распакуйте проект целиком в обычную папку.
2. В VS Code выберите **File → Open Folder** и откройте папку SciNav.
3. Установите расширение **Live Server** от Ritwick Dey, если его ещё нет.
4. Нажмите правой кнопкой по `index.html` и выберите **Open with Live Server**.
5. Страница откроется по локальному HTTP адресу. Для поиска через OpenAlex нужен интернет.

Для проверки использован движок Live Server из расширения 5.7.10. Сборка и установка зависимостей проекта не требуются.

## Выполнено по заданию

- Оформлены шапка, первый экран, поиск, фильтры, карточки, таблица источников и подвал.
- Все основные стили подключены внешним файлом `css/style.css`.
- Цвета, шрифты, отступы и радиусы заданы CSS переменными в `:root`.
- Flexbox используется в шапке и внутри карточек, Grid — для сетки карточек.
- Основные медиазапросы: 1100 px и 600 px; отдельно учтено уменьшение анимации.
- Есть состояния `:hover`, `:focus-visible`, `:active` и `:disabled`.
- Пустая тема поиска показывает сообщение об ошибке и выделяет поле. При запросе кнопка отключается.
- Иконки встроены как SVG. Длинные названия и метаданные переносятся через `overflow-wrap`.
- Проверены ширины окна 375, 390, 1440 и 1920 px: ширина документа не превышает ширину окна.
- Полноразмерные скриншоты 1440 и 390 px находятся в `screenshots/`.

## Функции и ограничения

JavaScript получает до шести публикаций через публичный API OpenAlex, сортирует загруженные результаты, сохраняет источники в localStorage и экспортирует черновик библиографии в TXT. Сортировки «Новое» и «По дате» сейчас одинаковы. «Все» и «По релевантности» сохраняют порядок ответа API.

Автооценка 1–10 — эвристика по совпадению слов запроса с заголовком, цитируемости и полноте метаданных. Полный текст статьи не анализируется. Начальные карточки демонстрационные и повторяют макет, их оценка 8/10 не является результатом анализа реальной статьи. Авторизация и серверная база данных не реализованы.
