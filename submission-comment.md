# Комментарий к работе

Оформлены шапка, первый экран, окно поиска, фильтры, карточки источников и подвал по макету SciNav. Стили вынесены в css/style.css. Через :root заданы общие цвета, шрифты, отступы и скругления. Для шапки и карточек используется Flexbox, для сетки источников — Grid.

Подготовлены desktop и mobile версии. Проверены ширины 1440, 390, 375 и 1920 px. Добавлены состояния наведения, фокуса и нажатия, оформление ошибки пустого запроса и недоступной кнопки во время загрузки. Полные скриншоты страницы приложены.

Основная сложность — повторить скруглённое окно поиска и перестроить элементы на телефоне без горизонтальной прокрутки. Нужна консультация по визуальному порядку фильтров: в мобильном макете они находятся над поиском, а в HTML — после него. Сейчас это реализовано свойством order; порядок клавиатурной навигации остаётся по HTML.
