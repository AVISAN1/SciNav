# Комментарий к работе

Выполнена простая статическая вёрстка SciNav на HTML и CSS. Оформлены шапка, первый экран, поиск, фильтры, четыре карточки и подвал. Стили вынесены в css/style.css; визуальные переменные заданы через :root. Использованы Flexbox, Grid и два основных медиазапроса.

Подготовлены версии для desktop и mobile. Состояния элементов оформлены через hover, focus-visible, active и disabled. JavaScript пока не подключён; поиск, фильтры и экспорт отключены, оценки демонстрационные.

Сложность — повторить форму окна поиска и перестроить фильтры на телефоне. Нужна консультация по доступному порядку блоков: CSS order меняет визуальный порядок, но не порядок чтения HTML.
